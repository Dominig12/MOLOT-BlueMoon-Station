/proc/generate_tracer_lightingLights a beam path, a turf list in path order. A short-range light touches only its own tile corners, and inside a straight run two neighbours share a corner edge, so every other tile at double power gives the shared corners the same sum. The alternation goes on through turns; only the edges next to path ends and diagonal steps differ by one light.
