PREF_JOURNAL_BASE_KEYКлюч блока журнала с отпечатком savefile на момент начала журнала: если файл с тех пор менялся мимо журнала, блок устарел.
PREF_JOURNAL_BLOCK_BEGINСтрока, с которой начинается каждый блок журнала: обрывок до неё (недописанный блок) не читается.
PREF_JOURNAL_BLOCK_ENDСтрока, которой заканчивается каждый дописанный блок журнала: блок без неё оборван и не читается.
PREF_JOURNAL_EPOCH_KEYКлюч поколения в блоках журнала прошлого формата: при чтении пропускается.
PREF_JOURNAL_MERGING_SAVE_KEYКлюч savefile с отпечатком файла до начатого слияния журнала, оборванного падением.
