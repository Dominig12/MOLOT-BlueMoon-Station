/proc/player_save_debug_directoryПуть строится только из нормализованного ckey, без пользовательских частей пути.
/proc/player_save_debug_filesОтносительные пути нужны и для выбора файла, и для сохранения структуры при разборе бага.
/proc/player_save_debug_textJSON читается как текст даже при повреждении. Старый savefile открывается только на копии.
/proc/player_save_debug_slot_by_hashНомер слота по имени раздела в каталоге .d/: файл называется md5 ключа слота.
/proc/player_save_debug_describeРазбор строки файла: вид, номер слота. Имя персонажа добавляет вызывающий из корня.
/proc/player_save_debug_root_summaryИмена персонажей и активный слот берутся из сырого корня: учётная запись при этом не открывается и ничего не пишет.
/proc/player_save_debug_bundleВсе сейвы одним JSON: тексты как есть, старые savefile - в виде ExportText, его возвращает ImportText.
/datum/player_save_inspectorОкно отладки сейвов: файлы игрока по слотам, просмотр и выгрузка. Читает диск, ничего не пишет в сейвы.
