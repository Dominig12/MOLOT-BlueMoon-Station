/datum/unit_test/economy_ui_cargo/express_ordersЭкспресс-заказ с бюджета снабжения: открытая консоль заказывает пак своего каталога по его цене, запертая ничего не заказывает, скрытый пак не заказывается; взломанная берёт ящик-залог без скидки и пять паков только со склада, где их пять.
/datum/unit_test/economy_ui_cargo/bundle_departmentПачка скупки собрана для одного отдела из его каталога, первым - то, что отделу нужно сейчас; канал отдела слышит о ней не чаще BUNDLE_RADIO_COOLDOWN. За бюджет отдела её берёт глава из окна бюджета или снабжения, без денег в бюджете - нет; рядовой сотрудник и глава чужого отдела - нет.
/datum/unit_test/economy_ui_cargo/bundle_department/first_dibsЕсли отдел услышал о пачке и на смене есть кому её одобрить, первые BUNDLE_DEPARTMENT_FIRST её берут только за бюджет отдела; потом - снабжение и лично, лично - только при деньгах на цену с наценкой, которую окно знает от сервера. Почему пак нужен отделу, видят его сотрудники, глава и окно бюджета, чужим - только имя пака, а прошедшая нужда пропадает. Канал отдела слышит, как взяли пачку, и кто - только если не лично.
