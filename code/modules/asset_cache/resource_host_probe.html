code/modules/asset_cache/resource_host_probe.dm

RESOURCE_PROBE_TIMEOUTСколько ждать ответа адреса ресурсов.
RESOURCE_PROBE_MIN_ARCHIVE_RATIOАрхив меньше этой доли локального .rsc - почти наверняка от другой сборки или битый.
RESOURCE_PROBE_LOCAL_RSCИмя ресурсного файла сборки рядом с .dmb.
RESOURCE_PROBE_OKНачало вердикта живого адреса.
/proc/probe_client_resource_hostsПроверка адресов, которые сервер раздаёт клиентам: внешний архив ресурсов (EXTERNAL_RSC_URLS) и CDN ассетов (ASSET_CDN_URL). Мёртвый архив не виден ни в одной ошибке: клиент молча тянет каждый ресурс по игровому сокету, и эту работу BYOND делает в главном потоке мира. Пишет в asset.log по строке на адрес с вердиктом, плохие адреса - ещё в лог мира и админам.
/proc/resource_probe_headHEAD-запрос через rustg без блокировки мира. Список с ключами code, length, type, modified, error.
/proc/resource_probe_verdictСтрока для лога по ответу resource_probe_head(). archive - ждём zip с .rsc внутри, local_rsc_size - размер .rsc сборки (0 - неизвестен).
/proc/report_resource_probe_problemsПлохие адреса ресурсов - в лог мира и админам. При инициализации мира админов в игре ещё нет: тогда сообщение ждёт старта раунда.
/proc/resource_probe_admin_messageВ вердикте заголовки и текст ошибки от удалённого хоста как есть: в чат админам они идут экранированными.
/datum/resource_probe_reportДержит сообщение о плохих адресах ресурсов до старта раунда.
