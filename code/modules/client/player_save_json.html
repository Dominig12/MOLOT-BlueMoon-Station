Space Station 13 - Modules - Types

code/modules/client/player_save_json.dm

/proc/player_save_revisionСогласует небольшие кэши корня между несколькими датумами префов одного аккаунта.
/proc/player_save_unescape_textКаждый % в экранированной строке начинает код: исходные % записаны как %25.
/proc/player_save_compatibility_savefileЗначения старых модулей проходят через savefile; новый временный файл на каждое значение стоил ~2 мс.
/proc/player_save_copy_treeЧитает значения исходного savefile через >>, пишет в целевой через << и рекурсивно копирует каталоги.
/proc/player_save_encode_treeПереносит все узлы, включая неизвестные текущим загрузчикам поля и скрытые слоты.
/proc/player_save_validate_treeПроверка снимка без записи каждого поля во временный savefile.
/datum/player_save_documentСнимок раздела. Общие узлы неизменяемы; первая правка отделяет дерево читателя.
/proc/player_save_merge_treeПисатель присылает только известные ему поля; неизвестные поля и ветви сохраняются.
/proc/player_save_slot_nameНормализация названия слота, одинаковая для кэша, диска и индекса.
/proc/player_save_slot_indexЗапись слота в корне: имя персонажа и название слота с тем же поколением, что и анкета. Строка вместо списка - корень сборки без названий слотов, название тогда берётся из анкеты.
/proc/player_save_slot_index_fromИндекс текущего каталога savefile со слотом.
/datum/player_save_character_transactionКорень публикуется после раздела, как и в старой транзакции через savefile.
/datum/player_save_jsonДва поколения: оборванная запись одного файла не повреждает другое поколение.
/proc/read_single_pref_journalЗначения из журнала одиночных ключей старого сейва: блоки с отпечатком savefile base или merging_base, поздние перекрывают ранние. Оборванные и устаревшие блоки пропускаются.
/proc/player_save_apply_legacy_journalДописывает в копию старого сейва незалитый журнал одиночных ключей. Сам журнал и исходный .sav не трогаются: после переноса их перекрывает JSON. TRUE, если копия изменилась.
/proc/player_save_is_slot_keyУзел анкеты в корне старого сейва: character1, character2...
