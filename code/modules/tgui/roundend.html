code/modules/tgui/roundend.dm

/proc/server_roundend_tgui_fileФайл с tgui-снимком последнего раунда сервера.
/datum/roundend_reportФасад tgui для отчёта о конце раунда. Один датум на клиента, чтобы повторное открытие обновляло уже существующее окно, а не плодило новые.
/proc/build_roundend_tgui_dataСтроит структурированные данные для tgui-отчёта.
/proc/load_roundend_tgui_dataЧитает сохранённый tgui-отчёт из файла. Возвращает null, если файла нет.
/proc/save_roundend_tgui_dataСохраняет tgui-отчёт в файл, чтобы его можно было посмотреть после рестарта.
/proc/build_legacy_roundend_tgui_dataОтдельный payload для tgui, когда структурированный снимок отчёта отсутствует (отчёт остался от версии до появления tgui).
