/datum/hk51_part_scatterРаскладывает части HK-51 на старте раунда: мотиватор на фабрику HK, одну часть на чёрный рынок, одну в шкаф техтоннелей станции, остальные по ящикам названных руин без гост-ролей, по одной на руину; не хватит руин - в шкафы техтоннелей других зон, затем второй раз в руину, но не в фабрику.
/proc/hk51_named_ruin_areaБезымянная зона руины - «Unexplored Location»: по такому названию место не найти.
/proc/hk51_ruin_familyВерхний предок зоны руины со своим названием: зоны одной базы делят семейство.
/proc/hk51_ruin_frameРамка загруженного шаблона руины вокруг его метки: list(x1, y1, x2, y2, z), без шаблона - null.
/proc/hk51_ruin_mark_atМетка шаблона руины, в рамку которого попадает турф.
/proc/hk51_place_groupРуина или зона места: по ней раскладка разводит части, по одной на группу. Руина - рамка её шаблона, вне рамок - семейство зоны.
/proc/hk51_place_hintПодсказка о месте части: зона и сектор, либо чёрный рынок.
/proc/hk51_area_labelИмя зоны для бирки; зона без имени руины получает имя шаблона («DK Excavator 453: Bridge») или общего предка («The Skelter: Storage»).
