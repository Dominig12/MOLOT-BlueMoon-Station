/proc/econ_bounty_fits_scannerСканер продажи берёт только предметы: заказ на костёр или лодку им не сдать.
/datum/econ_contract/delivery/outpostЗаказ аванпоста: награда - бюджету аванпоста, доля участника - сдавшим сканером продажи. Станционные доски и пады его не видят, а станционный спрос он не трогает.
/proc/econ_outpost_sayЭкспресс-консоли аванпоста id говорят вслух: слышат те, кто рядом, без радио.
/proc/econ_outpost_contracts_shipЗасчитывает предмет и его содержимое по заказам аванпоста id и удаляет засчитанное. Возвращает строки о тронутых заказах: сколько сдано или что выполнен.
/proc/econ_outpost_scan_destinationКуда сканер аванпоста id отправит вещь, в том же порядке, что и сдача: для подсказки до телепортации.
/proc/econ_outpost_income_reportСтроки итогов раунда о заработке аванпостов: только тех, кому что-то пришло.
/proc/econ_outpost_earnings_uiЗаказы аванпоста id и открытые спецзаказы партнёров для окна экспресс-консоли аванпоста.
/proc/econ_outpost_contracts_examineСтроки осмотра сканера аванпоста о его заказах.
