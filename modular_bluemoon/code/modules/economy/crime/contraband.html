/proc/econ_build_contraband_cacheСбой сборки не выключает изъятия на раунд: флаг сборки снимается всегда, следующий тик СБ пробует снова.
/proc/econ_station_obtainable_typesВсё, что экипаж получает без аплинка: фабрикаторы, карго, автоматы и раздатчики очков, призы аркады, лут блюспейс-крана, снаряжение должностей и лоадаут. По типам, не по машинам на карте.
/proc/econ_note_loot_itemsСпавнер вне карты не раскладывает лут и сразу удаляется, но его список читается.
/proc/econ_contraband_base_valueЦена контрабанды без рынка: ТК аплинка по курсу настроек, стопка - по числу штук.
/proc/econ_contraband_limitБольше этого NT и Вольные торговцы за предмет не платят: текущая цена чёрного рынка, а за купленное - потолок выкупа; null - потолка нет.
/proc/econ_contraband_creditsЦена изъятого в кредитах по рынку контрабанды; при unit_price - в кредитах оценки, которые NT оплачивает по этому прайсу. Вместе с премией офицеру выплата не выше потолка предмета.
/proc/econ_contraband_valueОценка изъятия для оплаты работы СБ: кредиты оценки по прайсу WORK_SEC_CONTRABAND.
/proc/econ_blackmarket_priceЦена лота чёрного рынка по рынку контрабанды.
/datum/export/contrabandКонтрабанду покупает только контрабандный партнёр и только с отгрузкой с допуском контрабанды; иначе она возвращается шаттлом. Вне рынка станции (пиратский пад) - обычные экспорты.
/proc/econ_customs_chanceШанс таможенного досмотра ящика: базовый, выше во время инспекции Sol и при красном коде и выше.
/proc/econ_customs_scanТаможня NT досматривает отгружаемый ящик: найденная контрабанда изымается, остальное остаётся в грузе, штраф платит отдел накладной ящика или снабжение. Высыпанное из изъятого ящика попадает в released. Возвращает оценку изъятого.
/proc/econ_release_non_contrabandИз изымаемого контейнера всё, что не контрабанда, высыпается в drop и попадает в released; вложенная контрабанда уходит вместе с ним.
