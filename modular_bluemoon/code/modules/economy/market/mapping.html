Space Station 13 - Modules - Types

modular_bluemoon/code/modules/economy/market/mapping.dm

/proc/econ_packaging_valueСколько NT платит за пустую упаковку этого типа: первый подходящий экспорт, как при продаже.
/proc/econ_material_exportЭкспорт, по которому NT покупает материал как сырьё: экспорт материала, а без него - экспорт его листа.
/proc/econ_materials_valueМатериалы -> id товара рынка -> базовая цена этих материалов как сырья.
/proc/econ_cap_valueЦена потолка по текущему рынку товаров сырья.
/proc/econ_value_listБазовая цена предмета как список id товара -> цена: его потолок, если он собран на станции, иначе его экспорт.
/proc/econ_mark_station_madeСобранное на станции стоит для NT не дороже своих материалов, из купленных - не дороже их выкупа; вложенное - не дороже своих.
/proc/econ_take_stack_capДоля потолка стопки за amount штук: отнимается у стопки и возвращается, null - если потолка нет.
/proc/econ_merge_stack_capСлияние стопок: потолок переходит вместе со штуками, у стопки без потолка он начинается с её собственной цены.
/proc/econ_mark_assembledМашина из рамы стоит как рама и плата; детали внутри продаются сами по себе.
/proc/econ_add_part_valueДеталь, поглощённая сборкой, переходит в цену собираемого.
/proc/econ_add_assembly_valueДобавляет к цене собираемого долю share от цены поглощённого.
/proc/econ_mark_mech_assembledМех стоит как всё, что поглотили шасси и шаги сборки; батарея и модули внутри продаются сами по себе.
/proc/econ_cargo_market_helpСправка консолей снабжения одной строкой: все пункты econ_cargo_help_topics() подряд.
/proc/econ_cargo_help_topicsСправка консолей снабжения по темам: list(title, icon, lines). Вольных торговцев называет только консоли с допуском контрабанды.
/proc/econ_express_help_topicТема справки экспресс-консоли, перед общей справкой снабжения.
/proc/econ_pack_tradedПак идёт через торговых партнёров: рыночный, не из каталога отдела, не особый, не эмаговый и не контрабанда.
/proc/econ_pack_supplierПоставщик пака или null; для пака мимо партнёров - тоже null.
/proc/econ_pack_unavailableПака нет ни у одного открытого партнёра: заказ ждёт пополнения склада. Пачка скупки ждёт, пока её продавец под эмбарго.
/proc/econ_buyer_factorМножитель лучшего покупателя; контрабандный партнёр покупает только отгрузку с допуском контрабанды.
/proc/econ_import_resale_factorКупленное через снабжение NT выкупает не дороже нижней границы рынка: так перепродажа ящика не окупает его закупку.
