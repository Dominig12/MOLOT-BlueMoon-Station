Space Station 13 - Modules - Types

modular_bluemoon/code/modules/economy/market/cargo_ui.dm

/datum/econ_cargo_pricesЦены, поставщики и наличие паков, рынок и партнёры для окон снабжения. Пока окна подписаны, пересчёт раз в ECON_CARGO_PRICES_REFRESH.
/proc/econ_cargo_window_pricesОбщая таблица цен: тип пака -> list(цена, id поставщика, в наличии); имя поставщика окно берёт из партнёров. Окну уходят только строки его каталога.
/proc/econ_cargo_supply_idsПаки каталога окна по его группам: таблица цен окна несёт только их.
/proc/econ_cargo_live_dataИзменчивая часть окна снабжения: цены паков pack_ids, рынок и партнёры. Уходит со статикой и частичным обновлением после пересчёта, а не с каждым обновлением окна.
/proc/econ_cargo_pushШлёт окнам host то, что сменил пересчёт после seen = list(версия цен, рынка, каталога): смена состава каталога - всей статикой, цены и рынок - частичным обновлением. Возвращает новые версии.
/proc/econ_cargo_window_staticСтатика окна снабжения: справка, каталог и цены, рынок и партнёры для него. Возвращает её, в pack_ids кладёт паки каталога.
/proc/econ_partner_visibleПартнёр виден в окне: контрабандный - только на взломанной консоли снабжения.
/proc/econ_cargo_price_rowСтрока таблицы цен по SSmarket.best_offer(): без поставщика - цена рынка, и пак в наличии, только если идёт мимо партнёров.
/proc/econ_cargo_pack_entryЦена, поставщик, товар рынка и наличие пака для строки каталога; поставщик - только из видимых окну партнёров.
/proc/econ_cargo_static_entryНеизменная часть строки каталога окна снабжения; цена, поставщик и наличие - в econ_cargo_live_data().
/proc/econ_pack_contentsОпись пака для карточки каталога: "имя ×N" по списку contains, одинаковые предметы сложены.
/proc/econ_cargo_shuttle_dataГде шаттл снабжения и сколько секунд до прибытия: state - station, centcom, to_station, to_centcom, recharging, loaned или away.
/proc/econ_cargo_suppliesГруппы каталога снабжения без цен: цены уходят отдельной таблицей econ_cargo_live_data().
/proc/econ_cargo_static_dataСправочные числа окна снабжения, общие для консоли и приложения.
/proc/econ_cargo_ui_dataДинамические данные окна снабжения, общие для консоли и приложения КПК.
/proc/econ_cargo_messageСообщение ЦК об отгрузке; сделки с контрабандным партнёром - только окну, которое его видит.
/proc/econ_cargo_add_amountСколько одинаковых паков добавить по нажатию: amount из окна в пределах 1..ECON_CARGO_ADD_MAX, без него - один.
/proc/econ_cargo_auction_bidСтавка на аукционе из окна снабжения с личного счёта; ответ произносит speaker.
/proc/econ_cargo_auction_buyoutПокупка лота экипажа сразу из окна снабжения с личного счёта; где ждать посылку, говорит окно и карта.
/proc/econ_cargo_given_reasonПричина заявки из окна или null, если окно её не прислало.
/proc/econ_cargo_order_refusedОтказ заказать пак сразу, до вопроса о причине; отказ произносит speaker.
/proc/econ_cargo_private_accountЛичный счёт по ID в руке для частного заказа; без него отказ произносит speaker.
/proc/econ_cargo_new_orderНовый заказ от имени user: в очередь заявок или сразу в корзину снабжения.
