modular_bluemoon/code/modules/economy/market/offer.dm

/datum/market_offerСпецзаказ партнёра: товар, количество, цена единицы с множителем и срок.
/proc/econ_offer_item_matchesКупленное не засчитывается, кроме тары из автомата, если нужный реагент в неё налили уже после покупки: правило контрактов поставки.
/proc/econ_offer_payee_nameКому ушла доля маржи выполненного спецзаказа, для сообщения ЦК и лога.
/proc/econ_pad_offer_payeeОтдел, которому платит сдача спецзаказа с пада: отдел счёта сдавшего, без него - снабжение.
/proc/econ_offers_shipЗасчитывает предмет и его содержимое по спецзаказам партнёров с пада подработки или, с budget, сканером аванпоста. Возвращает принятые штуки.
/proc/econ_pad_offers_uiСпецзаказы, которые можно сдать на паде, для доски контрактов.
/proc/print_offer_manifestНакладная спецзаказа: печатает консоль снабжения для взятого спецзаказа.
