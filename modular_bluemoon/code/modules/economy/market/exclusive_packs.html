/proc/econ_exclusive_okЭксклюзивный пак везёт только свой партнёр и только со ступени exclusive_tier; обычный - любой.
/proc/econ_partner_suppliesПартнёр сейчас может везти пак: открыт, не под эмбарго, продаёт группу, пак на складе; контрабандный - только с допуском.
/proc/econ_order_supplierПоставщик заказа: выбранный при заказе партнёр, если он ещё может везти, иначе самый дешёвый. Пачку скупки везёт только её продавец и только не под эмбарго.
/proc/econ_order_costЦена заказа у его поставщика.
/proc/econ_requested_partnerПартнёр из окна для нового заказа: только тот, кто сейчас может его везти; иначе null - поставщика выберет цена.
