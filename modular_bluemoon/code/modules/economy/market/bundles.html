Space Station 13 - Modules - Types

modular_bluemoon/code/modules/economy/market/bundles.dm

/datum/supply_pack/bundleПачка скупки: несколько паков каталога одного отдела у одного партнёра в одном ящике, только целиком и со скидкой. Цена фиксирована при выставлении.
/proc/econ_bundle_whomДля кого пачка, в названии: "Скупка для медбея".
/proc/econ_bundle_source_okПак годится в пачку: seller его везёт, внутри только вещи, не опасный, не из личного каталога и сам по себе не дороже BUNDLE_VALUE_MAX.
/proc/econ_bundle_takenКанал отдела пачки слышит, как её взяли: how - "за бюджет отдела", "за бюджет снабжения" или "лично". За бюджет - и кто, по ID-карте из заказа; личного покупателя не называют.
/proc/econ_bundle_sellerПродавец пачки, если он сейчас может её продать: открыт и не под эмбарго; иначе null.
/proc/econ_bundle_departmentОтдел, для которого собрана пачка скупки; не пачка - null.
/proc/econ_bundle_buy_for_departmentПокупка пачки за бюджет её отдела: как заказ пака каталога главой - глава отдела, ГП или капитан, деньги списываются сразу. Возвращает list(успех, ответ).
/proc/econ_cargo_buy_bundleПокупка пачки из окна снабжения: за бюджет её отдела (budget) - глава, ГП или капитан; за бюджет снабжения - снабжение; или лично, если все её паки продаются лично и на счёте хватает на цену с наценкой частного заказа. Пока идёт окно department_left(), только за бюджет отдела. Заявкой скупку не взять, у партнёра под эмбарго - тоже. Пачка уходит в корзину и пропадает из скупки.
/proc/econ_bundles_ui_dataСкупка для окон снабжения и бюджета отдела (only_department - только пачки этого отдела); can_budget - user может взять пачку за бюджет её отдела. need - пак, который отделу нужен сейчас; почему нужен (need_why) видят окно бюджета, сотрудники отдела и те, кто берёт пачку за его бюджет: в причине бывают данные датчиков.
