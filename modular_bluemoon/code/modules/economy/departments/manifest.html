Space Station 13 - Modules - Types

modular_bluemoon/code/modules/economy/departments/manifest.dm

/proc/econ_manifest_department_forОтдел, на который пользователь может выписать накладную: свой отдел, кроме самого снабжения.
/proc/econ_print_manifestПечать накладной с консоли: свой отдел, кулдаун по счёту сотрудника, а не по консоли.
/proc/econ_crate_manifestНакладная отдела в ящике; накладная спецзаказа отделом не считается.
/proc/econ_crate_offerСпецзаказ по накладной в ящике; в ящике учитывается только один, о лишних накладных - строка в отчёт.
/proc/econ_sell_crateПродаёт ящик со всем содержимым и раскладывает выручку. Сначала таможенный досмотр, затем спецзаказ по накладной забирает своё. department_shares собирает доли отделов по имени.
/proc/econ_pay_crateВыручка ящика: без накладной отдела - снабжению, с ней - отделу за вычетом сбора снабжения.
