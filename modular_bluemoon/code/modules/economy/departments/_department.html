Space Station 13 - Modules - Types

modular_bluemoon/code/modules/economy/departments/_department.dm

/proc/econ_budget_nameРусское имя счёта для текстов: бюджет отдела, бюджет внестанционной фракции или имя владельца личного счёта.
/proc/econ_staff_statsСотрудники всех отделов за один проход по счетам: id отдела -> on_shift, owed_wages (без внестанционных), payroll, owed_to_staff. Процы отдела берут её аргументом stats, без него собирают только для себя через only_department.
/proc/econ_emergency_activeКрасный код и выше: NT не забирает излишек бюджетов, чтобы отделам было на что восстанавливать станцию.
/proc/econ_saving_goal_queueОтделы с ещё не набранной целью накопления, кроме source, от самой ранней цели к поздней.
/proc/econ_public_nameИмя для журналов и заявок отдела: по ID-карте, как на кассе и в снабжении, а не настоящее имя под маской.
