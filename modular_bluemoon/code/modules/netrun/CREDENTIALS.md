# ID погружения и ключи добытых прав

При погружении настоящий список доступов ID тела один раз сохраняется в приватный файл `dive-id.access`. Пока длится это погружение, смена или извлечение физической карты не меняет снимок. Новый доступ тела появится при следующем погружении. Снимок виден среди файлов с источником «сессия»: его можно удалить, немедленно отозвав эти ID-права до выхода.

Сессионный файл не попадает на общий диск импланта, не копируется, не перемещается на шард, не загружается в узел и не предлагается другому процессу. Возврат, потеря тела или уничтожение связи удаляют его. Обычные `.access`, отдельно извлечённые из реального ID-источника командой `extract_credentials`, сохраняют свои прежние правила хранения.

«Выпустить ключ» создаёт обычный переносимый файл `.grants` из подтверждённых результатов взлома узлов и шлюзов. Права стартового проживания, ID, пароли серверов и состояние взломанной прошивки не входят в ключ. Автовзлом узла записывает USER; взлом шлюза — GUEST. Более сильные обычные результаты ручного взлома сохраняют свой фактический уровень.

Ключ работает только пока его реальный файл находится в памяти или подключённом шарде. Он повышает эффективные сетевые права, но не легальный ID-доступ и не проходит нативный `allowed()` машины. Его использование не записывает права навсегда в новую сессию: файл можно копировать обычным способом, а удаление последнего источника немедленно отзывает его эффект.

Каждая область ключа привязана к исходному объекту, сети и её текущему ключу. Поднятие сетевого экрана отзывает все старые копии права на этот узел; смена привязки узла или ротация ключа ЛВС также делает соответствующие области недействительными. Копирование устаревшего файла сохраняет старые метки отзыва. Чтобы выпустить действующий ключ заново, нужно действительно получить доступ заново.

Backend: `access_session.grant_node(node, level, export_level)` и `grant_network(network, level, export_level)` отдельно хранят эффективный и доказанный переносимый уровень. Обычный код наследования передаёт только доказанный уровень источника; сырой совместимый `node_access`/`network_access` без такого доказательства не подписывается при экспорте. Интерфейс использует `acquired_key_payload()` и `export_acquired_key(name, to_shard)`.
