proc
request_statpanel_icon
(/client/C, /atom/A)

URL иконки атома для панели осмотренного турфа.

Готовая иконка отдаётся сразу. Новую считает IconForge в своём потоке, и тогда возвращается null: картинку клиенту отправит poll_icon_jobs(), когда задание закончится. STATPANEL_ICON_BUSY - все слоты заданий заняты.

Метаданные DMI без разбора иконки в DM: rust читает заголовок файла, ответ кэшируется на файл.

list(list(ширина, высота), list(стейт = число направлений)) либо null для рантайм-иконок, которые печатаются не путём к .dmi, и для файлов, которые rust не прочитал.

proc
statpanel_icon_spec
(/atom/A)

Описание иконки атома для IconForge - та же картинка, что раньше рисовали в DM icon2html() (базовый стейт) и costly_icon2html() (getFlatIcon с оверлеями). Сами пиксели считает rust в своём потоке: в DM холодный разбор DMI и Blend'ы флаттена шли одним куском на 30-270 мс.

Возвращает описание спрайта, STATPANEL_ICON_NOTHING (рисовать нечего) или null - в иконке есть рантайм-/icon, и её рисует старый DM-путь.
