Space Station 13 - Modules - Types — Var Details - Proc Details

account
/datum/player_save_json/account

Корень и слоты записываются отдельно: одиночная настройка не переписывает все анкеты. Корень хранит точные поколения разделов и публикуется последним при каждой транзакции.

Vars

migration_publishedTRUE, когда последний перенос опубликовал корень JSON.
migration_sourceПоэтапный перенос старого .sav: открытая копия файла и ещё не записанные разделы.

Procs

abort_migrationОбрывает перенос. Разделы без корня никто не читает, следующий перенос их перепишет.
begin_migrationОткрывает копию старого .sav для переноса по разделам. FALSE с error - файл не прочитан, FALSE без error - переносить нечего.
character_indexМеню не загружает все анкеты заново после каждой смены вкладки или настройки корня. Результат: ключ слота -> list(имя персонажа, название слота).
commit_branchЗаписывает раздел key из source, его поколение кладёт в next_directories.
finish_migrationКорень публикуется последним: до него читатели видят только старый .sav.
legacy_character_fieldsОдно поле каждой анкеты старого .sav из одной копии файла, без разбора анкет целиком. Список полей вместо одного даёт по анкете список значений в том же порядке.
legacy_marker_pathОтпечаток .sav, из которого перенесён JSON. Новые сборки .sav не пишут, так что другой отпечаток значит, что после переноса играли на старой сборке и JSON устарел.
legacy_onlyJSON ещё не опубликован: незаконченный перенос оставляет только файлы разделов без корня.
migration_stepОдин раздел или, когда разделы кончились, корень. TRUE - перенос закончен: опубликован (migration_published), упал (error) или прерван чужой записью.
set_aside_stale_jsonУстаревший JSON уходит в отдельный каталог, и сейв заново переносится из .sav. FALSE - отложить JSON не удалось, чтение блокируется до разбора вручную.
