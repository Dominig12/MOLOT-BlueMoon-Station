Space Station 13 - Modules - Types — Var Details - Proc Details

crew_request
/datum/econ_contract/crew_request

Объявление экипажа: заказчик кладёт награду в депозит, исполнитель получает её, когда заказчик примет работу.

Vars

announce_timerОтложенная строка по общему каналу
poster_mob_refКто дал объявление: мут IC перепроверяется перед строкой по радио
report_countНомер сдачи: таймер автоприёмки старой сдачи не срабатывает на новую
reportedИсполнитель сдал работу и ждёт решения заказчика
settledДепозит уже выплачен или возвращён

Procs

after_dropОтказ исполнителя: объявление снова свободно и остаётся на доске до своего срока.
announceСтрока по общему каналу без имени заказчика: объявление ещё свободно, заказчик не в муте, канал и личный кулдаун заказчика свободны. TRUE, если прозвучала.
rejectЗаказчик отклоняет сданную работу: исполнитель снят без штрафа, объявление снова свободно.
reportИсполнитель сдаёт работу: заказчик принимает или отклоняет её, а промолчит ECON_CREW_REQUEST_ACCEPT_TIME - работа принята.
schedule_announceОткладывает строку по общему каналу на ECON_CREW_REQUEST_ANNOUNCE_DELAY. Возвращает пояснение для заказчика.
