econ_test_obtainable
/datum/econ_test_obtainable

Что экипаж добывает сам. Купленное в автоматах и через снабжение контракт не засчитывает, но оно годится в дело: из него крафтят, его режут и растят.

Vars

examine_spotГде создавать разбираемые предметы: часть из них при создании смотрит на то, где лежит
examinedПредметы, уже разобранные на реагенты и содержимое
input_kindsТип -> TRUE, если в руках есть он сам или его подтип: рецепты ищут ингредиент по istype
inputsТип, который есть в руках у экипажа, купленный тоже -> откуда
itemsТип предмета, который можно отправить по контракту -> откуда он берётся
plantableСемена, которые можно посадить: из автомата, снабжения и мутаций тоже, ведь урожай уже не покупка
reagentsТип реагента -> откуда
symptom_sumsПоказатель симптома -> "число симптомов:сумма" -> типы симптомов

collect_transformsНарезка, готовка, объедки, доски из брёвен, семена из урожая, своя плата - в машину, своё шасси - в меха, кухонный процессор, флора Лаваленда.
